# Лист — тестовая веб-версия

[Открыть приложение](https://bobratko-rgb.github.io/leaf-web/)

Публичный репозиторий доставки готовой веб-сборки. Исходный проект остаётся закрытым.

## Проверенная сборка

- Версия: v0.2.0-journal
- Исходная ревизия: 8af8795fc7bed893cca0b826ef4e449e6a57a059
- Облачная сборка: 38160136555, web и Android успешно завершены; 52 теста приложения и 5 браузерных тестов.
- Архив: https://github.com/bobratko-rgb/leaf-web/releases/download/v0.2.0-journal/leaf-web-pwa.zip
- SHA256: b1642cd2243ed7b3f933c747778782f06815858498b3cd70c5a457542205956d

Карточки растений, журнал процедур с комментариями, даты посадки и возраст, фотографии с датами и подписями, четыре независимых интервала ухода. RU, EN, DE, FR, ES, AR с RTL.

Сайт сохраняет прежний адрес для переноса локальной коллекции. Данные и фотографии хранятся в браузере на устройстве. Физические iOS/Android, Safari и камера ещё требуют проверки на устройствах; успешная облачная сборка её не заменяет.

Pages скачивает закреплённый архив, проверяет SHA256 архива и каждого файла по release-files.json, настраивает базовый путь /leaf-web/ и размещает CanvasKit вместе с приложением.
